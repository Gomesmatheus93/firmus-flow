# Skills que alimentam o `estrategista`

Material de referência em `third_party/instagram-agent-skill/` (MIT, Jake Schincariol).
Não editamos nada lá: o que a gente aproveita é escrito no `prompt.md` daqui.

| Skill     | O que aproveitar                                                     |
| --------- | -------------------------------------------------------------------- |
| `ig-plan` | a semana: o que postar, em que formato, quando, e com quem interagir |

## Notas

O `ig-plan` monta semana para **uma pessoa** que grava os próprios vídeos. Aqui o
planejamento é para uma **empresa**, e quem aprova é o chefe — o plano sai como proposta,
não como calendário já publicado.

A parte de "com quem interagir" só vira ação de verdade quando a automação de comentários
estiver liberada pela Meta. Até lá é sugestão na tela.
